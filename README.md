Riparazione rapida di computer, notebook, smartphone e tablet nel cuore di Roma. Diagnosi gratuita, ricambi originali e assistenza in negozio.

> 🚀 **Demo live:** [https://jryahia.github.io/pc-smartphone/](https://jryahia.github.io/pc-smartphone/) — hosted on GitHub Pages

## Cosa offre il sito

- Riparazione PC e notebook
- Sostituzione schermi smartphone
- Riparazione tablet
- Recupero dati
- Diagnosi gratuita
- Assistenza in negozio

## Perché questo sito

- **100% single-file** — HTML, CSS e JavaScript in un unico file, senza dipendenze esterne
- **Mobile-first e responsive** — verificato a 360 / 768 / 1200 px
- **SEO ready** — dati strutturati JSON-LD, meta description, semantica HTML
- **Conversione** — CTA chiare, link telefonici e WhatsApp click-to-chat, mappe integrate
- **Accessibilità** — contrasto WCAG-aware, navigazione da tastiera, preferisce-movimento-ridotto
- **Prestazioni** — nessuna libreria esterna, caricamento immediato

## Tecnologie

HTML5 · CSS3 · JavaScript (vanilla) — zero framework, zero dipendenze
